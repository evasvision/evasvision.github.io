# Eva’s Vision — проект для Claude Code

Это полная переносимая копия опубликованного сайта на 11 октября 2026 года (версия 10).

Сайт: https://evas-vision-studio.brainy-kid-8124.chatgpt.site

## Как продолжить

1. Распакуй ZIP на Mac.
2. Открой распакованную папку `evas-vision-claude-code` в Claude Code.
3. Напиши: «Прочитай CLAUDE.md и README.md. Это мой сайт-портфолио Eva’s Vision. Сохрани текущий дизайн, фотографии, чешскую и английскую версии и прайс. Дальше я буду давать изменения».

## Как посмотреть сайт локально

Открой терминал в папке проекта и выполни:

```bash
python3 -m http.server 8000
```

Затем открой http://localhost:8000 в браузере.
Остановить сервер: Ctrl+C. Для этого способа нужен Python 3.
Можно также открыть `index.html` прямо в браузере; для стабильной работы предпочтителен локальный сервер.

## Что внутри

- `index.html` — структура страницы, стили, тексты на двух языках и интерактивность.
- `fonts.css` — подключение локальных шрифтов.
- `assets/` — логотип, цветок для кнопок, портреты Евы и обе серии портфолио.
- `assets/fonts/` — Instrument Serif, Manrope и файлы лицензий.
- `CLAUDE.md` — контекст и указания для продолжения разработки.
- `EXPORT.json` — версия и контрольные суммы экспортированных файлов.

## Что уже сделано

Чешская и английская версии, адаптивная верстка, кремово-розово-шоколадная палитра, фоновые элементы, цветочные кнопки и анимации с поддержкой reduced motion, портреты Евы, услуги, прайс, контакты и раздел AI & Transparency.

В Portfolio находятся:

- Clay Court Summer — 3 фотографии, описание из предоставленного info.md; независимый AI-концепт, вдохновлённый Alo Yoga; инструмент Nano Banana.
- Soft Structure — 3 фотографии с кремовой сумкой и шоколадным костюмом; рабочее название, выбранное при добавлении серии. Название бренда и инструмент не указаны.

У каждого проекта есть раскрывающаяся галерея. Фотографии открываются в крупном просмотре с переходом кнопками и стрелками клавиатуры, закрытием через Escape и кнопку. Раздел Video пока содержит заглушку.

## Публикация на GitHub Pages

Сайт лежит в корне репозитория и публикуется GitHub Pages напрямую из ветки `main` (Settings → Pages → Source: Deploy from a branch, `main`, `/ (root)`). Адрес: https://evasvision.github.io/. Пути в EXPORT.json указаны с префиксом `dist/` — так было в исходном экспорте.

## Публикация (исходная заметка экспорта)

Это самостоятельная копия исходников. Изменения в этой папке автоматически не обновляют существующий сайт. Для публикации на другой платформе загружай `index.html`, `fonts.css` и папку `assets` как статический сайт. Чтобы обновить текущую ссылку ChatGPT Sites, понадобится отдельная публикация изменений в исходном проекте.

Последняя проверка: синтаксис JavaScript, тексты обоих языков и alt-тексты, локальные изображения, ссылки разделов и расчёты пакетов. Визуальная проверка страницы в браузере не выполнялась.
